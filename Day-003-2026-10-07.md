# Day 3 - Reverse a String

## Problem

Take a string as input and output its reverse.

Input: `hello there`  
Output: `ereht olleh`

## Code

```java
import java.util.Scanner;

public class Program
{
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        String s = scanner.nextLine();
        char[] arr = s.toCharArray();

        int left = 0, right = arr.length - 1;

        while(left < right) {
            char temp = arr[left];
            arr[left] = arr[right];
            arr[right] = temp;

            left++;
            right--;
        }

        System.out.println(arr);
    }
}
```

## How It Works

The string is converted into a `char` array:

```text
hello there
↓
[h][e][l][l][o][ ][t][h][e][r][e]
```

Then `left` starts at the beginning and `right` starts at the end.

The characters at `left` and `right` are swapped, then both move toward the middle.


Final result:

```text
ereht olleh
```

## Key Learnings

* `toCharArray()` → converts a `String` into a `char` array.
* `arr.length` → gives the size of the array.
* `arr.length - 1` → gives the index of the last element.
* `left` starts at `0`, while `right` starts at `arr.length - 1`.
* `while(left < right)` → continues swapping until the middle.
* `temp` → temporarily stores a character while swapping.
* `left++` → moves left forward.
* `right--` → moves right backward.
