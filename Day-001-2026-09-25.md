## 📚 Problem
### Time Converter

A program to convert days to seconds.

The given code takes the amount of days as input. Complete the code to convert it to seconds and output the result.

### Sample Input
```text
12
```

### Sample Output
```text
1036800
```

### Explanation
12 days are 12 * 24 = 288 hours, which are 288 * 60 = 17280 minutes, which are 17280 * 60 = 1036800 seconds.

## 💻 Code

```java
import java.util.Scanner;

public class Program {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        int days = scanner.nextInt();
        int hrs = days * 24;
        int mins = hrs * 60;
        int seconds = mins * 60;
        System.out.println(seconds);
    }
}
```

## 🧠 What I Learned

- How to take integer input using `Scanner`.
- How to convert days into hours, minutes, and seconds.
- How to use variables to perform calculations step by step.
- 1 day = 24 hours.
- 1 hour = 60 minutes.
- 1 minute = 60 seconds.

## ⭐ Key Takeaway

I practiced breaking a problem into smaller calculations:

**Days → Hours → Minutes → Seconds**
