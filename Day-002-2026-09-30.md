# Day 2 - Java Loan Calculator

## Problem

Calculate the remaining loan amount after 3 months.

Each month, 10% of the remaining amount is paid.

Input: `20000`
Output: `14580`

## Code

```java
import java.util.Scanner;

public class Program
{
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int amount = scanner.nextInt();
        int remaining = amount;
        int payment;

        for(int i = 1; i <= 3; i++) {
            payment = (10 * remaining) / 100;
            remaining = remaining - payment;
        }

        System.out.println(remaining);
    }
}
```

## Calculation

```text
20000 → 18000 → 16200 → 14580
```

10% is calculated as:

```text
(10 * remaining) / 100
```

## Key Learnings

* `for` loop → repeats the calculation 3 times.
* `remaining = remaining - payment` → updates the value after each month.
* `X% of Y = (X * Y) / 100`
* `%` in Java means **remainder/modulus**, not percentage.
* `10 / 100` with integers gives `0` because of integer division.
